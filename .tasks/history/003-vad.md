# 003 — VAD + инкрементальная транскрибация

## Цель

Сейчас транскрибация запускается только после того, как пользователь остановил запись, и обрабатывает весь наговорённый текст одним куском. Это неудобно при длинных диктовках — текст не виден до самого конца.

Нужно:
1. Во время записи детектить паузы в речи (VAD — Voice Activity Detection)
2. На каждой паузе вырезать наговоренный сегмент и сразу отправлять его на транскрибацию
3. Текст печатается инкрементально, по мере появления пауз
4. Пользователь видит результат постепенно, а не одним блоком в конце

## Архитектура

### VAD (энергетический)

Прямо в `callback` sounddevice (вызывается ~32 раза/сек при 512-байтных блоках на 16kHz):

```
callback(indata):
  if RECORDING:
    segment_buffer.append(indata)
    rms = sqrt(mean(indata^2))
    if rms > vad_threshold:
      silence_frames = 0
    else:
      silence_frames += 1
      if silence_frames > silence_limit and len(segment_buffer) > min_segment_frames:
        # конец сегмента
        queue.put(segment_buffer[:])
        segment_buffer.clear()
        silence_frames = 0
```

### Очередь сегментов

- `queue.Queue` — потокобезопасная FIFO
- В `callback` кладём сегменты
- Фоновый поток `transcriber_thread` забирает сегменты и обрабатывает

### Фоновая транскрибация

```python
def transcriber_loop():
    while True:
        segment = segment_queue.get()
        if segment is None:  # сигнал остановки
            break
        write wav → tempfile
        run whisper-cli → text
        xdotool type text
```

### Остановка записи (push-to-talk, задача 002)

При `on_release(key)`:
1. Остановить запись
2. Если в `segment_buffer` остались данные — отправить их как последний сегмент
3. Послать `None` в очередь (сигнал остановки потоку)
4. Дождаться, пока поток обработает все оставшиеся сегменты (`thread.join()`)

### Конфиг `~/.config/voice-input/config.toml`

```toml
vad_threshold = 0.005        # RMS-порог: ниже этого — тишина
vad_silence_ms = 2000        # сколько мс тишины нужно для разделения
vad_min_segment_ms = 300     # минимальная длина сегмента (меньше — игнор)
```

### Граничные случаи

- **Очень короткая пауза** (< `vad_silence_ms`): не режем, продолжаем копить
- **Очень короткий сегмент** (< `vad_min_segment_ms`): игнорируем (шум/сбои)
- **Сегмент накопился, но whisper-cli ещё не закончил предыдущий**: очередь растёт, поток обрабатывает последовательно
- **Очередь > 5 сегментов**: объединяем оставшийся буфер в один большой сегмент (предотвращает лавину)
- **Ошибка whisper-cli**: логируем, но не останавливаем запись
- **push-to-talk отпущен до первого сегмента**: тишина весь сегмент — `"No speech detected"`
