# 002 — Push-to-Talk

## Цель

Заменить текущий toggle-режим (Insert — старт, Insert — стоп) на push-to-talk (зажать и говорить, отпустить — стоп). Это даёт более интуитивный контроль: пока держишь клавишу — запись идёт, отпустил — транскрибация.

## Что изменится

### Поведение клавиши

Сейчас:
```
on_press(key):
  if recording → stop recording, transcribe
  if not recording → start recording
```

Станет:
```
IDLE → [press] → ARMING (ждём 300ms)
ARMING → [release] → IDLE (ничего не было — тап)
ARMING → [таймер сработал] → RECORDING (реально пишем звук)
RECORDING → [release] → проверяем длительность записи:
  если < 2s → "Cancelled", чистим → IDLE
  если >= 2s → транскрибируем → IDLE
```

### Конфиг `~/.config/voice-input/config.toml`

```toml
mode = "push-to-talk"  # или "toggle" в будущем
```

По умолчанию — `"push-to-talk"`.

### Файлы для изменений

- `voice_daemon.py`:
  - Добавить `import time`, `import datetime`
  - Глобалы: `PRESS_TIME`, `RECORD_START`, `ARM_TIMER`
  - `log()` — таймстемп с миллисекундами (`%Y-%m-%d %H:%M:%S.%f`)
  - `on_press`: запуск `threading.Timer(0.3, _arm_timer)`, логи `"Key pressed"`
  - `_arm_timer()`: сброс `ARM_TIMER = None`, старт записи
  - `on_release`: отмена таймера + `"Key released — arm cancelled"`, `"Key released"`, проверка 2s, `"Cancelled"` или транскрибация
  - Учесть `CFG["mode"]` — структура готова к расширению
  - Лог: `Ready. Hold {key} to record`
